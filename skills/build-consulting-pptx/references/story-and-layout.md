# Story and layout reference

## Sequence selection

Use the smallest sequence that answers the decision:

1. Executive answer and decision frame
2. Data/business context and quality boundary
3. External context when sourced
4. Two to five evidence slides
5. Synthesis and business implication
6. Prioritized recommendations
7. Methodology and limitations
8. Decision summary / next action

Add or remove evidence slides based on actual artifacts. Do not pad the deck.

## Archetype selection

| Evidence need | Preferred layout |
|---|---|
| One decisive trend | Full-width chart with takeaway |
| Comparison plus interpretation | Chart left / insight right |
| Ranked drivers | Horizontal ranking with annotation |
| Three findings | Three evidence cards |
| Segment trade-offs | Comparison matrix |
| Prioritized actions | Recommendation table or priority cards |
| Model rules | Connected decision-tree rule boxes |
| Caveats | Limitations with mitigation/validation action |

## Hierarchy

- Headline: the conclusion, normally one or two lines.
- Main visual: the evidence that proves the headline.
- Takeaway: one short interpretation or decision implication.
- Caveat/source: close to the evidence, visually quieter but readable.

Use asymmetry and whitespace to establish focus. Avoid equal-weight grids when one result matters more.
